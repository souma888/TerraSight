Planned pipeline

From capture to evidence

  1. 01

    Capture or upload

    Use existing photos or follow guided capture in a mobile browser.

  2. 02

    Check readiness

    Assess image quality, feature matches, viewpoint diversity, and likely coverage gaps.

  3. 03

    Reconstruct

    Estimate camera poses and build terrain geometry, then inspect registration and completeness.

  4. 04

    Analyze and report

    Connect segmentation to 3D geometry and present supported measurements with uncertainty.

Safe capture matters. Never approach an active landslide or unstable slope for imagery. This project is an experimental analysis tool, not an early-warning system or a substitute for a qualified assessment.
